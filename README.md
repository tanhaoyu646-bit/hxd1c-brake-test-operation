# HXD1C 列车自动制动机试验

本项目是从 HXD1C 发车作业项目指定基线隔离得到的独立副本，不沿用原项目 GitHub 远程仓库。

当前开发范围：列车自动制动机简略试验。

- 确认列车管定压稳定
- 自阀减压 100 kPa
- 记录并判断列车管排风时间
- 保压 1 min 并检查漏泄
- 查询尾部风压并确认最后一辆车制动作用
- 自阀回运转位，确认尾部风压恢复和最后一辆车缓解
- 桌面端及手机横屏操作

## 试验判定与记录单

试验结论与操作评分是**两条独立的口径**，记录单上分列呈现：

- **试验结论**（合格 / 不合格）只由物理判定决定：列车管定压、减压量、排风时间、保压时间、
  列车管漏泄量、列尾制动确认、列尾缓解确认七项。
- **操作评分**（百分制）只反映操纵规范程度：流程完成 60、一次减压到位 15、排风时间判断 15、
  列尾查询效率 10，再扣无关设备操作分（每次 3 分，上限 15 分）。分高不等于试验合格。

流程走完或中止时会自动出具记录单（也可点「查看试验记录单」重新打开），支持复制纯文本与打印/另存 PDF。

异常工况的处置原则：

| 异常 | 处置 |
|---|---|
| 排风时间过短 / 过长 | 流程照常走完（仍须确认制动与缓解作用），但结论判**不合格**并给出检查方向 |
| 保压漏泄超限 | 直接判不合格并中止，提示查明漏泄处所 |
| 尾部风压持续不跟随（连续 4 次查询且超过 20 s） | 判定列车管未贯通，判**不合格**并中止，避免学员无限重查 |

## 参数

- `?debug=1`：将保压时间缩短为 6 秒，仅用于开发调试；记录单上会标注"调试模式，不得作为正式记录"
- `?scenario=short`：排风时间过短场景（同时模拟尾部风压响应迟缓）
- `?scenario=long`：排风时间过长场景
- `?scenario=leak`：保压漏泄超限场景

`?scenario=` 属于**教学场景注入**：正式教学可用它构造异常工况，检验学员能否判定为不合格。
