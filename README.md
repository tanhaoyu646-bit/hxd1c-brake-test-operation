# HXD1C 列车自动制动机试验

本项目是从 HXD1C 发车作业项目指定基线隔离得到的独立副本，不沿用原项目 GitHub 远程仓库。

当前开发范围：列车自动制动机简略试验。

- 确认列车管定压稳定
- 自阀减压 100 kPa
- 记录并判断列车管排风时间
- 保压 1 min 并检查漏泄
- 查询尾部风压并确认最后一辆车制动作用
- 自阀回运转位，确认尾部风压恢复和最后一辆车缓解
- 桌面端及手机横屏操作

调试参数：

- `?debug=1`：将保压时间缩短为 6 秒，仅用于开发调试
- `?scenario=short`：排风时间过短场景
- `?scenario=long`：排风时间过长场景
- `?scenario=leak`：保压漏泄超限场景
