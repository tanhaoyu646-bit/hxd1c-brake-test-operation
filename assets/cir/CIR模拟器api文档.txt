========== 关键变量解释 ===========
	mmiheight - 页面高度
	mmistate	  - MMI当前状态（0副控，1主控，2主菜单，21车次号注册，22运行区段，23查询通讯录，26输入列尾ID，27维护界面，28状态查询，30出入库检测，31调度命令信息，32进路预告信息，33出入库检测信息，100发送报警信息前确认，101已发送报警信息，108出入库按键检测）
	netstate	  - 网络状态（0G网，1模拟）
	pagecount  - 总页码数
	currentpage- 当前页码
	pagestep     - 页码步进
	menuopcount - 主菜单某一选项序号
	infostate      - 签收状态，0未签收，1已签收
	segpagecount - 运行区段路局目录页码
	
	数组mmiinfo - 0车次号，1列尾号，2机车号，3风压，4调令函头信息，24调令内容
	数组infosave  - 0当前信息条数，1-9调令函头div元素序号

========== 函数功能解释 ===========
	buttonfix(button_code)
		功能：判断按下哪颗按键并调用相应函数
		参数解释：
			- button_code : 按键代码，值为字符串类型，范围"bt1"-"bt12、"rt1"-"rt32"

	drawmenu()
		功能：绘制主菜单

	menuoptionlight(key_type)
		功能：主菜单光标绘制
		参数解释：
			- key_type : 光标移动方向，值为字符串类型，"down"或"up"

	getinfomationwin(info_type)
		功能：绘制信息（调度命令、列车进路预告、出入库检测）窗口
		参数解释：
			- info_type : 信息类型，值为字符串类型，"ddml"、"jlyg"、"crkjc"

	drawcommandwindow()
		功能：绘制命令窗口

	maininterfaceinit()
		功能：绘制MMI主界面

	getmode(modecode)
		功能：在“运行区段”项目中选择线路时返回被选线路的通信制式

	readtraintype()
		功能：车次号注册后，播放车次类型（C、G、D、K、T、Z）音频

	readnumber(number_type)
		功能：播放相应数字音频及需要的功能音频
		参数解释：
			- number_type : 数字类型，值为字符串类型
					"cch" - 车次号	"lwlj" - 列尾连接	"lwxh" - 列尾销号
					"lwdqr" - 列尾待确认	"jch" - 机车号	"pf" - 排风
					"fb" - 风压报警	"fy" - 风压

	getpagecount(page_type)
		功能：填充各路局的线路数据时获取该路局线路信息的总页数
		参数解释：
			-page_type : 值为整数型，数字对应路局

	getcircurrenttime(time_type)
		功能：返回当前时间
		参数解释：
			- time_type : 值为整数型，取值范围1-3
				1 : 按格式“年月日时分秒”返回时间
				2 : 按格式“时分秒”返回时间
				3 : 按格式“hh:mm:ss”返回时间

	saveinfo(save_type)
		功能：当接收到信息时，保存相应数据至infosave数组
		参数解释：
			- save_type : 保存类型，值为整数型，取值范围1-2
				1 : 信息未签收
				2 : 信息已签收
